# digital-twin

Professional digital twin for applied AI and agentic systems.

This repository will contain a public career website combining a professional
profile, selected project case studies, and an evidence-grounded AI dialogue.
Its focus is practical AI engineering, controlled agentic systems, integration
architecture, and working implementations.

## Current status

The project is in its foundation phase. The initial source material is being
curated before the application architecture and implementation stack are
selected.
